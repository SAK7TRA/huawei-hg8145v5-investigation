# Huawei HG8145V5 Access Investigation

A documented, authorized investigation of web-management access recovery on a Zain-customized Huawei EchoLife HG8145V5 GPON ONT.

## Contents

- [`huawei-hg8145v5-access-investigation.md`](huawei-hg8145v5-access-investigation.md) — investigation notes, confirmed findings, limitations, and safety considerations.
- [`screenshots/`](screenshots/) — sanitized interface image for documentation.

## Scope

This case study documents device identification, review of local web assets, offline review of account metadata in a configuration backup, and precautions taken to avoid unnecessary service disruption.

It does **not** claim to have decrypted password fields or discovered a universal recovery method. Use these techniques only on equipment you own or are explicitly authorized to administer.

## Sensitive data

Do not commit configuration backups, passwords, salts, Wi-Fi keys, WAN/PPPoE credentials, ACS secrets, serial numbers, GPON identifiers, or unredacted screenshots.
